# 🧠 Jake Enterprise Suite

AI 기반 GPT 상담 플랫폼 + 보안 CRM + 이상탐지 + 보안 파일관리 시스템

## 📦 구성

- Vue3 or React 기반 관리자 대시보드 (`client/`)
- Express + MongoDB + GPT API (`server/`)
- AI 이상탐지 모듈 (Python, `analytics/`)
- Slack/Webhook, Mail 알림, 디지털 서명
- Docker 기반 전체 배포 (`docker-compose.yml`)

## 🚀 배포

```bash
docker-compose up --build


## 🔐 보안 기능
- JWT + OAuth2 인증
- 디지털 서명 + 해시 + RBAC
- 침입 탐지 + AI 이상 행동 탐지
